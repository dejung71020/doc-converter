제공된 대상 템플릿 문서의 시각적 레이아웃 구조를 정밀하게 분석하여 HTML/CSS 변환을 위한 구조화된 JSON 형식으로 반환하세요.

[엄격한 제약 조건]
1. 문서에 실제로 눈으로 확인되는 레이아웃 구조와 필드만 추출하세요. 없는 요소를 임의로 상상해서 추가하지 마세요.
2. 폰트는 Google Fonts에서 제공하는 서체 중 가장 유사한 후보 3개를 추천하세요.
3. 모든 색상은 반드시 '#'을 포함한 HEX 코드(예: #FFFFFF)로 표기하세요.
4. 반드시 지정된 JSON 형식으로만 응답해야 합니다. 시작과 끝에 ```json 등의 마크다운 기호나 앞뒤 설명 텍스트를 절대 붙이지 마세요. 오직 중괄호 { 로 시작해서 } 로 끝나야 합니다.

[복잡도 스코어(complexity_score) 계산 기준]
문서 레이아웃의 복잡도를 평가하기 위해 다음 항목들의 점수를 합산하여 최종 complexity_score를 계산하세요:
- 절대 위치를 지정해야 하는 독립 요소(position: absolute) 수 × 15점
- 가로 컬럼(Column) 수 (3개 이상 분할될 때만) × 10점
- 중첩 테이블(Nested Table)의 최대 깊이 × 20점
- 사용된 커스텀 서체(Font) 종류 수 × 5점
- CSS Grid 또는 Flexbox 레이아웃 적용 필요 구역 수 × 10점
